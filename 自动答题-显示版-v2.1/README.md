# 隐蔽复制粘贴助手

专为讯飞考试平台设计的浏览器插件，解除网页复制粘贴限制，**不触发切屏检测**。

## 安装方法

1. 打开 Chrome 浏览器，访问 `chrome://extensions/`
2. 开启右上角的「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择 `破解复制粘贴插件` 文件夹

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Alt + Q` | 启用/禁用插件 |
| `Alt + C` | 隐蔽复制（选中文本后使用） |
| `Alt + V` | 隐蔽粘贴（点击输入框后使用） |
| `Alt + S` | 解除选择限制 |

## 工作原理

### 防切屏检测
- 拦截页面注册的 `blur`、`visibilitychange`、`mouseleave` 事件监听器
- 所有操作在页面内完成，不会触发窗口焦点变化

### 解除限制
- 移除 `oncopy`、`onpaste`、`oncut` 等事件处理器
- 覆盖 CSS `user-select: none` 样式
- 清除元素上的限制属性

### 隐蔽复制粘贴
- 使用 Clipboard API 直接操作剪贴板
- 绕过页面的事件拦截机制

## 注意事项

1. 插件在页面加载时自动启用
2. 如遇问题，按 `Alt + Q` 切换插件状态
3. 部分网站可能需要刷新页面后才能生效
4. 建议在考试前先测试插件功能

## 文件结构

```

├── manifest.json    # 插件配置
```

# 显示版新增（v2.0 进阶层）

在原「复制粘贴」兜底层（零改动）之上叠加 AI 自动答题显示功能。

## 快捷键

| 键 | 功能 |
|---|---|
| `Alt+E` | 截屏当前答题页 → AI 视觉识别作答（进行中忽略重复按键） |
| `Alt+A` | 显示答案面板（常驻，不自动消失） |
| `Alt+X` | 隐藏答案面板（从 DOM 移除，不留痕迹） |
| `Alt+Z` | 把最新一批 AI 答案粘贴进当前输入框（不写系统剪贴板） |
| `Alt+Q` | 插件总开关（关闭后进阶层同时停用） |

原有 `Alt+C/V`、`Alt+1~9`、`Alt+D` 全部不变；AI 通道与预设通道完全独立，互不覆盖。

## 使用前配置 `ai-config.js`

1. `base_url`：中转站地址（不带 `/v1/chat/completions`）
2. `api_key`：中转站 Key
3. `model`：视觉模型名
4. `judge_word`：判断题用词（对/正确，须与考试页面文案一致）
5. `site_whitelist`：考试站点域名（空数组 `[]` 表示不限站点）
6. `keys`：Alt+E/A/X/Z 键位可改

## 题库 `question-bank.js`

按文件内示例格式填入 `{type, question, answer}`；题干经归一化（去空白/标点/题号、全角转半角、小写）取 MD5 指纹比对。题库命中优先于 AI，永远不被 AI 覆盖。

## 状态指示灯（右下角小圆点）

灰=空闲 · 黄(呼吸)=识别中 · 绿(2s)=成功 · 红(2s)=失败

## 安全边界

纯浏览器扩展内实现：截屏用 `captureVisibleTab` 无焦点变化；面板/toast/指示灯全部为页内 DOM；AI 答案走 `execCommand('insertText')` 回填，不触碰系统剪贴板；所有失败静默降级，兜底层不受影响。

⚠ `ai-config.js` 含 API Key，不得将此文件夹分发给他人。

## v2.1 更新（2026-11-18）
1. 截屏由 PNG 改为 JPEG（quality 70）：全屏 PNG base64 后常超 5MB，超出视觉模型图片上限导致识别失败、答案不显示（v2.0 答案不显示的最可能原因）。
2. 识别成功后自动弹出答案面板（ai-config.js `auto_show_panel: false` 可关闭）；Alt+X 依旧隐藏。
3. 失败原因写入扩展 Service Worker 控制台（chrome://extensions → 服务工作者 → 控制台），不再无声吞错。
4. 修复本地 helper 推送消息格式：单题对象现规范为数组后入库，面板不再显示 0 题。
5. 识别失败 toast 提示"按 Alt+E 可重试"。
注意：重新加载扩展后必须刷新网页，否则 content script 不会注入、快捷键全部无效。
